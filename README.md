# Anime Character Classification

## Introduction
A full-stack web application that brings a high-performance machine learning pipeline directly to the user. 
Built on the Django framework, this project features a clean, user-friendly interface that allows users to interact seamlessly with a custom deep neural network. 
Under the hood, it automates the curation and classification of anime character faces, handling large datasets through automated object detection and delivering intuitive, real-time categorization.

## Core Technologies

* Backend Framework: Django (Python)

* Frontend: Javascript/CSS
  
* Object Detection: YOLO

* Classification Model: ResNet18

## Features

* Full-Stack Integration: Bridges a heavy machine-learning backend with a lightweight, accessible Django web frontend.

* User-Friendly Interface: A slick, modern web UI that provides an intuitive experience for processing images and visualizing classification results.

* Automated Dataset Curation: Custom scripts engineered to automatically format, process, and rename a large-scale dataset of 4,000+ anime images.

* Face Detection & Cropping: Utilizes YOLO to accurately detect and extract character faces from full-frame images.

* Deep Learning Classification: Implements a locally trained ResNet18 model to accurately classify characters based on processed facial data.
